## ✨ What is MovieStream?

MovieStream is a modern movie streaming frontend inspired by today's cinematic streaming platforms.

The project focuses on creating a polished user interface with:

* 🎥 Cinematic hero section
* 🔎 Search functionality
* 🍿 Movie browsing interface
* 📂 Category sections
* ❤️ Interactive UI elements
* 📱 Responsive design for different screen sizes
* ✨ Smooth hover effects and animations

This is a **frontend project**, meaning it focuses mainly on the user interface and user experience.

## 🚀 How to Run the Project

### Option 1 — Open directly

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.

The website should open in your browser.

### Option 2 — VS Code Live Server

1. Open the project in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Click **Open with Live Server**.
